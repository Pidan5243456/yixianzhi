# 衣先知 Android 产品需求

版本：1.5.0 部署候选版。实施与验证状态见 [任务看板](../../task-tracker.md)；本文中的验收条件是交付要求。

## 用户与问题

用户已经有一些衣服，希望知道自己有哪些、如何组合，以及有需要时看看试穿效果。衣先知先把这些衣物整理成可复用的衣橱，再提供搭配和可选的 AI 帮助。

核心故事：用户给自己的衬衫和裤子拍照，手动保存到衣橱；选出两件搭配，取名“周一上班”并收藏。以后可以直接查看、修改或复用这套搭配。想看效果时，再选择自己的模特照片并主动生成试穿图。

上传不强制裁剪或抠图，原照片经本机压缩即可保存和组合。不要求用户为“保存一件衣服”“更换一件衣服”调用模型。去背景处理失败时，手动保存的衣物仍可使用。

## 两个主要场景

1. 家中衣物：今天拍照，归属选择“我已拥有”；明天穿什么由日期、场景和手动温度驱动免费规则，也可以自己选。缺件给部分组合，不用未购买衣物或预设冒充自己的衣服。保存包含条件，日后能复用。
2. 网购衣物：商品图归属选择“想买”，围绕它与已有衣服试搭；含未购买衣物的组合明确标记。购买后更新同一个衣物 ID。暂不抓取购物链接、不做订单或价格跟踪。

乱拍照片可以手动留存，但不会自动按“合格照片”送去生成。主动去背景/试穿时做用途对应的检查；无衣物、多目标、人物不适用则提示重拍/重新选图。服务未配置时这些入口禁用，录入和搭配仍可用。目标选择与自动分割多件照片不属于本版。

## 导航与页面

| 页面 | 入口与目的 | 主要操作 |
|---|---|---|
| 登录 / 服务连接 | 配置演示或自己的后端 | 邮箱验证码、连接检测、同步、备份 |
| 首次引导 | 可跳过的服装偏好 | 添加第一件，或试搭预设 |
| 穿搭 | 底部入口；默认我的穿搭 | 新建、查看、收藏；显式切换灵感示例 |
| 衣橱 | 底部入口；个人衣物和标记的预设 | 分类、搜索、编辑、删除、可选去背景、想买转已拥有 |
| 搭配工作区 | 选择衣物后的编辑区域 | 本地预览、保存搭配、AI 推荐、生成试穿 |
| 试穿记录 | 底部入口 | 查看已有结果，不重新生成 |
| 我的 | 底部入口 | 收藏、模特照片、账号、设置 |

辅助页面：添加/编辑衣物、创建模特、搭配详情、账号资料。页面文件名单由 [web-files.cjs](../../../scripts/web-files.cjs) 控制。

## 核心用户故事与验收

| 编号 | 用户故事 | 验收条件 |
|---|---|---|
| US-01 | 我第一次打开 App，要建立自己的衣橱 | 个人衣物初始为空；6 件预设可试搭/隐藏，不计为拥有；引导可跳过 |
| US-02 | 我只想录入衣物，不想付出生成费用 | 选图、编辑、保存、再次编辑全过程无模型调用 |
| US-03 | 我想保存一套穿搭，日后直接穿 | 衣物组合有独立 ID、名称和场景；无需生成图片即可保存、收藏和重开 |
| US-04 | 我想尝试其他组合 | 换衣、换模特、返回页面仅更新预览；不会自动生成 |
| US-05 | 我需要 AI 提供建议 | 明确点击推荐；默认使用个人衣物，仅主动选预设锚点时使用预设；个人为空时提示添加；返回组合后仍由用户决定保存或试穿 |
| US-06 | 我想生成一张效果图 | 单独确认使用 AI；使用提交时的衣物与模特快照；结果关联正确组合 |
| US-07 | 我整理衣橱时删掉了一件旧衣服 | 组合显示缺失衣物且可修改；不悄悄补回示例、不抹去已生成的历史 |
| US-08 | 我离线或换设备时仍需要资料 | 本机可保存；同步失败有状态；冲突不静默覆盖；换设备可恢复云端资料 |
| US-09 | 我离开生成页面后再回来 | 能查询原任务和已完成结果；重复查询不再次付费 |

## 视觉与文案

纯白背景、深色正文、少量黄色强调，使用 Noto Sans SC。衣物图片是页面主体；空状态只保留原因和下一步操作。移除装饰性提示小字，保留保存失败、同步冲突、费用及授权等会影响决策的信息。

“搭配拼图”表示本机叠图，不承诺真实合身；“AI 试穿效果”表示生成结果；本地演示合成应标为演示。试穿记录展示对应结果标签。

## 第一版范围与发布门槛

范围：账号与服务连接、衣橱、自配搭配和收藏、模特照片、想买试搭、免费条件选搭、可选 AI 去背景/推荐/试穿、结果记录、本机保存、云端同步与备份。

暂缓：日历、穿着统计、支付、会员、社交发布、电商购买、体型精确测量。当前账号数据不包含支付信息。

预算/授权、结果恢复、增量同步和备份迁移已接入并通过替身测试。正式发布前仍需真实后端联调、真机相机/相册/返回键及文件备份验证、正式签名、隐私文本和继承素材授权核验。调试 APK 构建成功不能代替这些验收。

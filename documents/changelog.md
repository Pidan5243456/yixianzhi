# 变更记录

## 1.5.1 前端文案 · 2026-11-22

使用 humanizer 检查13个产品页面及动态提示，精简重复口号、空状态和生硬措辞。“创建我的模特”改为“添加试衣照片”，换衣只提示选中/取消选择，不冒充已生成试穿。保留费用、授权、手动温度、同步冲突与失败提示。

授权说明改为实际配置的衣先知服务及本地或第三方模型。移除未实现的微信绑定说明和求五星话术，明确生成试穿需全身照；关于页显示当前版本。分类枚举、ID、API和数据结构未变。


## 1.5.0 日常与网购试搭 · 2026-11-22

- 已拥有/想买分开，购买更新同一衣物；原图与透明派生图独立保留。
- 免费选搭使用日期、场景、手动温度；缺件不给虚构完整组合。试搭含未购买衣物时明确标记。
- 本地 INSPECT/CUTOUT/TRYON adapter、真实禁用态、用途检查凭据及服务端结果合并；旧生成拆分入口移除。
- 业务数据升级到3，旧客户端同步被阻止；同步协议2与SQLite结构4保持。
- 修复能力查询期间账号切换、同ID换图和演示凭据跨模式使用；补充双图备份与新用户故事测试。

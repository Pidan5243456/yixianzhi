# 开发约定

源码和文档使用 UTF-8；业务变量用英文，面向用户的文字用中文。新代码保持原生 JavaScript，不引入重复状态框架。

页面脚本负责交互，共享状态通过 Store 和 LocalState 操作，API 由 AppAPI 访问。账号归属只使用服务端验证的身份，不能接受请求体里的 owner。禁止把令牌导出到备份或同步实体。

任何跨 await 的页面写入都须检查账号分区和 epoch；生成请求还须捕获不可变衣物、模特输入。只有持久提交完成后才能提示保存成功。导航等待本机图片处理与提交，网络生成由服务器保存和恢复。

默认不触发 AI。进入页面、换衣、切换模特、收藏、删除及同步不调用模型。禁止吞掉预算或授权错误后继续备用调用；实际供应商尝试统一通过成本网关。

身份、版本、媒体归属、输入大小由服务端检查。所有外部结果视为不可信输入；展示文本转义，模型返回的单品 ID 必须来自本次候选集合。

运行数据放 DATA_DIR，构建文件放 www/artifacts，全部忽略。测试只使用独立临时目录；不读取真实 .env 或数据库，不以真实付费调用作为默认验收。

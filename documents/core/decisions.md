# 产品与技术决策

下表记录选择与目标，不表示全部能力已接入。当前差异见各业务模块，执行状态见 [任务看板](../task-tracker.md)。

| 决策 | 选择 | 原因 |
|---|---|---|
| 产品基础 | 用户自己的衣橱 | 示例不代表用户拥有，不能自动填充 |
| 穿搭 | 可保存的衣物 ID 组合 | 手动组合无需生成图片，也能长期复用 |
| AI | 推荐、整理、试穿分别触发 | 用户能理解每次操作，服务能控制成本 |
| 图片 | 本机缓存与服务端私有文件分离 | 支持离线查看、换设备恢复和单张传输 |
| 数据库 | SQLite 单机 | 当前部署规模无需额外数据库服务；不支持多实例共享此库 |
| Android | Capacitor 原生容器 | 保留用户认可的页面和视觉 |
| 第一版范围 | 衣橱、搭配、可选试穿、可靠同步 | 日历、穿着统计、支付和商业会员留待后续 |

竞品调研参考 FITS ME 官网与商店、MyWear 商店和公开功能说明。借鉴功能关系，不复制其代码或付费素材。MyWear 官网与商店的容量、套餐描述不一致，未把宣传数字当作已验证能力。

仍需上线前完成：真实服务配置与小额联调、正式签名、真机权限与相册验证、运营主体信息及隐私文本、继承素材授权确认。内部费用预留不能替代供应商账户的账单硬额度。

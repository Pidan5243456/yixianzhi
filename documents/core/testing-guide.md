# 测试指南

所有命令从 yixianzhi 根目录运行。最新实际结果见 [验证记录](../testing/latest.md)；不要用旧仓库结果代替新仓库验收。

## 当前检查

| 命令 | 验证内容 | 边界 |
|---|---|---|
| `npm run build:web` | 产品白名单资源生成 | 不验证页面交互或 APK |
| `npm test` | OTP 并发消费、权限、CORS、静态边界、图片归属、快照 CAS、落盘失败、拆图幂等、重启恢复、生产缺配置 | 8 项接口测试；模型替身，不是真实 AI |
| `npm run test:product` | 空衣橱、手动增改、保存/收藏、自配重开、显式演示生成、删除后缺失、多尺寸页面；本地演示流程未产生 AI 接口请求 | 演示模式本就不请求后端，不能证明远程模式无自动调用；360/375/430/768/1440 浏览器视口，不是 Android 真机 |
| `npm run test:sync` | 图片全量同步、整份冲突、备份期间修改、失败保留、丢回执恢复、删除去重、轮询并发、跨账号旧响应 | 当前同步 v1；不是实体增量协议 |
| `scripts/verify-apk.ps1` | APK 签名、版本、包名、网页资源哈希和私有路径 | 不验证相机、相册或后台恢复 |

先安装依赖并构建网页，再执行浏览器测试。当前 Playwright 脚本使用 Windows Chrome 路径 `C:/Program Files/Google/Chrome/Application/chrome.exe`，其他环境需调整 executablePath。

测试设置 `NODE_ENV=test`、空供应商/邮件密钥及独立 `.tooling/tests/` 数据目录。API 和同步脚本禁止对外请求；产品脚本使用客户端本地演示。不得以真实账号、生产数据库或真实付费请求补齐测试。

## 改造中的必测项目

| 领域 | 必须验证 |
|---|---|
| 触发边界 | 远程模式使用 API/供应商替身计数，验证进入页面、换衣、返回和保存均不自动触发 AI |
| 授权 | 默认拒绝、撤回、重试和备用模型重新校验、读取已有结果不索取新授权 |
| 费用 | 无效请求不扣费、并发抢最后额度、去重、未知结果保留预留、跨日重试、操作累计上限 |
| 持久任务 | 关闭页面、服务重启、回执丢失、磁盘满、成功子项复用、旧 cycle 回调隔离 |
| 增量同步 | 分页并发、推送期间继续编辑、逐实体冲突、删除墓碑、旧版本迁移 |
| 媒体 | 跨账号引用、超容量、回收与新引用竞争、缺图、按需下载、超过 30 MiB 备份 |
| 账号生命周期 | 退出/服务切换时图片处理中、注销时任务在途、同邮箱重建 |
| 原生设备 | 相册选择/取消、相机返回、权限拒绝、文件导出、手势返回、切后台、进程终止 |

这些测试尚未全部编写或执行。文档验收还需检查相对链接、源码路径和“现状/目标”标注；文档范围评审不代替功能验收。
